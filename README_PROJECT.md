# TrimFuse AI

Streamlit prototype for AI-assisted semiconductor trim prediction and fuse-map safety auditing.

## Run locally
1. Install Python 3.10 or newer.
2. Open a terminal in this folder.
3. Create and activate a virtual environment.
4. Run `pip install -r requirements.txt`.
5. Run `streamlit run app.py`.

The app reads CSVs from `data/`. The datasets are synthetic and no fuse programming is performed. Read `IMPLEMENTATION_REPORT.md` for methodology and limitations.
